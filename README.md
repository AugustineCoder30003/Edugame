# EduGame

> *Learn Through Play.*

---

## Welcome

EduGame is an educational game platform where players learn by exploring, experimenting, and creating.

The first game in development is **VoxBox**, a voxel sandbox built completely from scratch in JavaScript using Three.js.

Every feature—from rendering to world generation—is designed to teach how game engines work while creating a fun experience.
